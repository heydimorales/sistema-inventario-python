# 📦 Sistema de Control de Inventario (Python & Base de Datos Relacional)

## 📌 Descripción del Proyecto
Este proyecto es un sistema backend enfocado en la administración eficiente de inventarios y control de ventas para negocios locales. Su objetivo principal es garantizar la integridad de los datos, evitar la duplicidad de información y optimizar el registro de transacciones mediante una base de datos relacional robusta.

---

## 🗄️ Arquitectura y Modelo de Base de Datos (DER)
El diseño relacional se compone de 3 tablas principales interconectadas:
1. **Productos:** Almacena el catálogo de artículos, precios unitarios y stock actual disponible.
2. **Clientes:** Contiene la información de contacto de los compradores.
3. **Ventas:** Registra las transacciones asociadas a un cliente y su fecha correspondiente.

---

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python
* **Base de Datos:** SQL Server / T-SQL
* **Control de Versiones:** Git y GitHub

---

## ✨ Características Principales
* Estructura de base de datos relacional optimizada con llaves primarias y foráneas.
* Consultas avanzadas (`JOIN`) para la generación de reportes de ventas cruzando datos de clientes y productos.
* Lógica backend en Python para interactuar con la base de datos de forma segura.
